# Fuji Gemco Homepage Redesign

A responsive, dependency-free homepage prototype built from verified public Fuji Gemco content and authentic assets from the existing website.

## Run locally

From this folder:

```powershell
python -m http.server 4173
```

Then open `http://localhost:4173`.

## Notes

- The original Fuji Gemco logo is used unchanged.
- Product, industry, project and client content is based on the existing public website.
- The contact form is intentionally non-transmitting in this homepage prototype.
- Published company figures should receive stakeholder approval before production launch.
